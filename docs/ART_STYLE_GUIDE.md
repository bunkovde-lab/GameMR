# GameMR — художественный регламент v1.0

## Назначение и статус
Визуальный источник истины — утверждённые изображения «Мир Раскола: Право на порядок». Они согласованы по **общей композиции**, но содержат демонстрационные числа, текст, условные подписи, иногда непоследовательные портреты. Их нельзя использовать как текстуру всей страницы с нарисованными неработающими кнопками.

## Художественная идентичность
- Научно-фантастический биопанк 2864 года, мрачный государственный монументализм, технологии наследственных постчеловеческих линий Багряных домов.
- Тёмные материалы, сдержанные багряные и бронзово-золотые акценты; контрастные диагностические цвета строго для статусов. Избегать декоративного свечения на каждом элементе.
- Оперативный персонал: различимые генетические признаки, физиологически обоснованное снаряжение и ранговые знаки; не обычная современная полиция в футуристической форме.
- Внутренние помещения и бойцы должны совпадать по масштабу/перспективе/свету. Не использовать обычное фэнтези, случайный киберпанк, безликие стоковые образы.
- Арт-изображения **без встроенных интерактивных надписей и чисел**; все строки, значения, кнопки и полосы из HTML/CSS/программных компонентов.
- На мобильном устройстве текст не должен превращаться в мелкую типографику из большого изображения.

## Слои и типы материалов
1. `backgrounds/`: полноформатный фон сцены или карты, без UI. Утверждённая городская карта неизменна.
2. `characters/`: персонажи, портреты, варианты состояний (здоров, ранен, в работе, погиб/архив) — отдельные файлы.
3. `locations/`: объекты инфраструктуры и крупные художественные изображения.
4. `events/`: иллюстрации происшествий, фаз спецопераций и итоговых отчётов.
5. `equipment/`: инвентарь, доказательства, органы и исследовательские устройства.
6. `ui/`: орнаменты, рамки, эмблемы и иконки — по мере необходимости, без печёного текста.

## Техническая передача
- Положения и требования — в `docs/ASSET_CATALOG.md`; стабильные ID в `assets/manifest.json`.
- Для художественных фонов — PNG-мастер, оптимизированный WebP для игры по решению программиста. Для прозрачных спрайтов — корректная альфа без белой подложки. Не выдавать вырезанный фон за прозрачный.
- Каждая поставка включает скриншот применения в настоящем интерфейсе на 16:9 и на горизонтальном планшете, проверку читаемости.
- Если производственный ассет отсутствует, использовать **обозначенный заглушкой блок** и завести арт-задачу, а не придумывать канонический портрет.

## Правило утверждения
Новые художественные варианты утверждает пользователь. Claude не изменяет финальный арт по собственной инициативе; выявленные технические проблемы документирует и передаёт арт-директору.
