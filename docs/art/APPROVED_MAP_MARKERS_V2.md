## Художественные характеристики
Единый острый ведомственный щит: матовый графит/чёрный металл, красный внутренний свет, состаренное бронзовое золото, чёткая иерархия узнаваемых символов. Для биологических угроз — анатомические и генетические мотивы; для служебного транспорта — действительная машина Дирекции. Это знаки **Багряных домов / Преемства**, а не обычный безликий набор веб-иконок.

## Важно для Claude: ограничения файлов
1. Исходный PNG содержит **подписи и декоративный фон** — использовать **только как дизайн-референс**, никогда как одну текстуру интерфейса.
2. Вырезанные WebP — **кадрированные референсы без прозрачности**, не готовые маркеры на карте. В них сохранён тёмный фон исходника.
3. Для игры нужны **отдельные прозрачные PNG/WebP с альфой** для расширенного размера знака и отдельные **упрощённые читаемые SVG 24×24** для небольших точек на карте.
4. Игровые SVG обязаны сохранять характерную геометрию герба и смысл пиктограммы; слепое уменьшение сложного арт-значка до 24×24 недопустимо.
5. Экспорт иконок в реальные `assets/ui/markers/` считать отдельной ART-задачей с проверкой при 32 px и на утверждённой карте. Не объявлять `integrated`, пока этого нет.
6. **Не добавлять `art_refs/` в `assets/manifest.json`**, поскольку данный manifest отражает только настоящие игровые файлы. После подготовки прозрачных/векторных файлов зарегистрировать их в manifest, проверить физическое наличие и присвоить статус.
7. Разрешена публикация изображений в публичном репозитории.
