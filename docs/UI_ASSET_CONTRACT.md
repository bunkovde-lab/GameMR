# GameMR — договор интерфейса и ассетов v1.0

## Отдельные ответственность кода и графики
**Графика** поставляет художественный фон, портреты, предметы, атмосферу. **Код** строит работающие кнопки, вкладки, контекстные меню, ползунки, показатели, маршруты, состояние и адаптивность.

## Хранение
- `assets/manifest.json` — реестр реально доступных файлов. Не добавлять несуществующие пути.
- Изображения группировать по назначению (`assets/backgrounds`, `assets/characters`, `assets/locations`, `assets/events`, `assets/equipment`, `assets/ui`).
- Готовую композицию экрана не превращать в единый фоновый скриншот с псевдокнопками.

## Рекомендованные состояния
- Боец: `available`, `assigned`, `in_transit`, `in_operation`, `injured`, `training`, `deceased`.
- Вызов: `new`, `assigned`, `en_route`, `active`, `resolved`, `expired`.
- Снаряжение: `available`, `reserved`, `damaged`.
- Кнопки: normal, hover/focus, selected, disabled, loading.
- Любой кадр получает данные от центрального state/store; не хранить дублированные mock-числа в компонентах.

## Интеграция первого вертикального среза
Карта W3 → выбрать вызов → карточка → быстрый выбор готового отряда → движение по дорожному графу → исход события → отчёт → изменение кадров и бюджета → сохранение и загрузка.

## Приёмка ассетов
Проверить: путь существует; формат читается; размер и пропорции корректны; alpha канал там, где заявлен; геометрия сцены соответствует персонажу; нет baked текста; активные контролы остаются доступными при масштабе и touch; права использования/происхождение задокументированы.
