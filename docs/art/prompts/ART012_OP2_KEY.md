# ART-012 / op2_key / «Красная герметизация»

Статус: поставлен на художественную приёмку. Исходное художественное направление утверждено, конкретный PNG — нет.

Стиль: научно-фантастический биопанк 2864 года, Багряные дома, государственный монументализм, реалистичная цифровая живопись. Графит, чёрный металл, глубокий багряный, бронзовые акценты, холодный медицинский свет. Никакого современного полицейского антуража, фэнтези, чрезмерного неона, текста, цифр, логотипов, UI, водяных знаков.

Сюжет: Первый Дом: аварийно изолированный биологический отсек, неантропоморфная культура в герметичном резервуаре, сотрудники в защитных костюмах.

Кадр: 1920×1080 RGB, главные действия в центральной зоне x=384..1536, y=324..756, без трупов, крупной крови, взрывов и монстров. Игрок выбирает, как поступить: изображение фиксирует напряжение перед действием, а не результат.

Файл сдан в отдельном PNG. В текущей поставке он сформирован из композиционного кадра с последующим мягким продолжением верхней/нижней зоны для сохранения центра; не генерировать из коллажа повторно.
