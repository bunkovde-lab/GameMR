# GameMR — музыка (ART AUDIO v1)

**Статус:** review (передано в GitHub для технической интеграции; работающий плеер ещё не проверен).

## Файлы
- `assets/audio/menu_theme.mp3` — тема главного меню (219.6 сек; MP3 stereo, 96 kbps; 2,635,694 байта).
- `assets/audio/gameplay_ambient.mp3` — музыка основной карты и панели Дирекции (204.8 сек; MP3 stereo, 96 kbps; 2,457,957 байт).

Файлы являются **веб-оптимизированными** копиями пользовательских оригиналов `Меню музыка.mp3` и `Фон к игре.mp3`. Исходники в MP3 (~189 kbps) сохранены в исходных вложениях разговора, но **не размещены в GitHub**; при необходимости полной исходной качества можно заменить эти файлы из оригиналов. Важно не выдавать веб-копии за байт-в-байт исходники.

## Задание Claude
1. Подключить проигрывание темы меню и фонового трека к сценам игры без изменения утверждённых артов или сюжета.
2. Обеспечить паузу, выключение звука и сохранение выбранной громкости. Не запускать звук без пользовательского действия, если браузер блокирует autoplay.
3. При переходе меню → игра сделать плавный crossfade, не запускать одновременно оба трека на полной громкости.
4. Предусмотреть loop и проверить стык файла — исходники Suno не гарантируют бесшовный loop.
5. Не подмешивать другой звук/голос автоматически. Не замораживать игровой цикл на ожидании аудио.
6. Проверить работу в браузере на ПК и планшете/телефоне. Просить пользовательскую художественную приёмку до объединения PR.

Пользователь дал явное разрешение разместить приложенные аудиофайлы в GitHub GameMR. Сохранение остальных художественных решений обязательно.
