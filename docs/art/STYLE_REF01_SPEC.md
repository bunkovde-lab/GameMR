## Что нельзя переносить из макета
- Городская картинка внутри `ref_01` — иллюстративная, **не утверждённая карта**. В игре только `assets/approved_map_original_1672x941.png` и конфигурация W3.
- Заголовок раннего макета «Контрразведывательная дирекция» некорректен: канонический заголовок — **«Городская дирекция безопасности»**.
- Числа, имена, вероятности, статусы и текст событий на арте — демонстрационные. Использовать данные ядра игры.
- Не подкладывать весь `ref_01` как картинку с фальшивыми кнопками.

## Типографика
- Основной интерфейс: **Golos Text** (кириллица), fallback `Segoe UI, Arial, sans-serif`.
- Крупные названия разделов: **Forum** (кириллица), fallback `Georgia, serif`. Не использовать декоративный шрифт для чисел, условий и длинных текстов.
- Заголовки секций 20–22 px, верхняя навигация и карточки 14–16 px, вторичный текст 14 px, HUD 19–23 px; минимальная интерактивная область **44×44 CSS px**.
- Шрифты следует подключать локально/через корректно лицензированный пакет при подготовке к офлайн-проверке. Не сохранять лицензионные шрифты в PR без проверки прав.

## Панели и свет
Графитово-чёрный металл, тонкая двойная бронзовая кромка (1–1.5 px), угловые срезы и орнаменты, скругления 6–8 px. Тень панели `0 12px 28px rgba(0,0,0,.65)`. Багряное свечение **только** на выбранном происшествии/вкладке/важной кнопке, не на каждом блоке.

## ART-008: ответ по восьми позициям

1. 9-slice рамка панели 256×256, безопасная угловая зона 48 px — **SVG в assets/ui/theme_ref01/**, при необходимости конвертировать в PNG.
2. Декоративная шапка 512×48 — **SVG**, без надписей.
3. Пять фонов кнопок 128×48 — **SVG или чистый CSS**, активные состояния всегда контролирует код.
4. Полоса HUD 1920×72 — **CSS**, большой графический PNG не нужен.
5. Нижняя навигация 1920×72 — **CSS**, большой графический PNG не нужен.
6. Герб Багряных домов — **требуется чистый утверждённый оригинал**; нельзя придумывать новый или обрезать из макета.
7. Шесть эмблем отрядов — отдельная художественная серия после подтверждения имён и лора; текущие заглушки не финальные.
8. Рамка карточки отряда 256×96 — **SVG** без персонализации, текста и иконок.

## Тест приёмки
- На 1920×1080, 1366×768, 1194×834 и 844×390 сопоставить скриншот игры с `ref_01`, сохранив **настоящую карту W3**.
- Убедиться, что интерфейс без прокрутки страницы, текст читается на планшете, кнопки доступны пальцем, selected/focus/disabled различаются без цвета.
- При сворачивании панели карта не прыгает и её относительные координаты не меняются.
- Не изменять игровые числа ради совпадения с нарисованными в референсе.

**Важный статус:** SVG-рамки из этого PR — технические художественные черновики для проверки масштаба и стилистики, не финальные изображения без приёмки владельца.
