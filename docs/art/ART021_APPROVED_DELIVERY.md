# ART-021 — Утверждённые медальоны навигации

**Статус:** 2026-11-10 владелец проекта просмотрел шесть медальонов и ответил «Подходит» — серия утверждена. Исходник — `GameMR_ART021_6_nav_icons_REVIEW.zip`, изображения сохранены из него без изменения пикселей.

## Для интеграции Claude

Пять значков в путях, которые ожидает код:

- `assets/ui/nav/nav_map.png` — Карта
- `assets/ui/nav/nav_staff.png` — Кадры
- `assets/ui/nav/nav_investigations.png` — Расследования
- `assets/ui/nav/nav_end_shift.png` — Завершить смену
- `assets/ui/nav/nav_saves.png` — Сохранения

Все PNG **512×512 RGBA**, прозрачный фон, медальоны единого стиля (состаренная бронза/золото, багряная эмаль).

**Важное исключение**: `art_refs/nav/nav_directorate_alternative.png` — одобренная **альтернативная** версия медальона «Дирекция». Текущую `assets/ui/kit_v2/crest_directorate.png` не заменять автоматически. В частности **не** создавать `assets/ui/nav/nav_directorate.png`, пока отдельным решением не выбрана замена герба.

Отображение состояний кнопок (выбрана/наведена/disabled) обеспечивает код, не встраивать дополнительные плашки и подсветку в изображения. Художественное утверждение ассетов **не означает** приёмку всей реализации навигации — проверьте 28px в игре на ПК и планшете.

Текущий Pull Request хранит исходники отдельно от изменения игрового CSS/JS и не меняет утверждённые арты.
