## Результат

Получен арт-лист 6×2 и подготовлены 12 отдельных портретов **PNG RGB 512×640**, без альфа-канала. Каждый исходный файл создан с сохранением пропорций лица и затемнёнными боковыми полями #141922. Для всех портретов используется общий свет; кандидаты не привязаны экипировкой к профессии. Текст, ранги и UI не включаются.

**Важно:** PNG **ещё не находятся в репозитории**. Оригиналы и individual prompt-файлы подготовлены отдельно в пакете `GameMR_ART009_12_Candidate_Portraits_REVIEW.zip` в разговоре с владельцем; Claude импортирует их в `assets/characters/` по мере художественной приёмки. **Нельзя** добавлять записи в текущий `assets/manifest.json` прежде чем реальные файлы доступны в этой ветке. Схема будущих записей приложена отдельно.

## Инструкция по приёмке

1. Пользователь проверяет лица и при необходимости запрашивает изменения, **без автоматического утверждения**.
2. После приёмки перенести все 12 файлов из архива в `assets/characters/` **без переименования**, добавить записи в `assets/manifest.json` как `approved` (если одобрена вся серия).
3. Claude проверяет лицо в квадратном кропе `x=96–416, y=16–336`, прежде чем подключать в `content/staff_v1.json → names`.
4. Случайный выбор должности не меняет портрет. Отображать то же лицо после найма в «Кадрах», отправке и отчётах.

## Ограничения

Исходник — составное изображение 1536×1024 (шесть колонок, два ряда). Файлы масштабированы из отдельных областей арт-листа, а не независимо созданы в нативном разрешении. Если на крупном экране деталей окажется мало, соответствующего человека нужно перерисовать отдельно, но не интерполировать лицо с искажением.
