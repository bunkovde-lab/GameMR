# M00-B — реализация главного меню (Claude Code)

**Дата:** 09–10.11.2026 · **Ветка:** `claude/project-thread-n44j1r` · **ТЗ:** [CLAUDE_MAIN_MENU_M00B.md](CLAUDE_MAIN_MENU_M00B.md)

## Ассеты (реально в репозитории)
Импорт `python scripts/import_m00b_assets.py GameMR_M00B_Claude_Handoff_v1.zip` — 24 файла, SHA-256 совпали с `docs/manifest.json` пакета.
- Исходники художника: `assets/menu/m00b/{background,logo,fx,ui/buttons,legacy_weatherkit}/` (зарегистрированы в `assets/manifest.json`, статус `review`).
- Веб-копии для сборки: `python scripts/build_m00b_web.py` → `assets/menu/m00b/web/*.webp` (эффекты: прозрачность = яркость, чтобы не нужен был `mix-blend-mode`; кнопки обрезаны по альфе для 9-slice; логотип 1086×362).
- Фон в сборке — `background/m00b_clean_1920x1080.webp` из пакета. Тяжёлые PNG в сборку не попадают.
- Референс с нарисованными кнопками — `art_refs/m00b_approved_composition_with_logo_ui.png`, только для сравнения.
- `legacy_weatherkit/` импортирован, но не используется.

Схема путей одна: импорт из `assets/` через `import.meta.glob` (`src/ui/menu/menuAssets.ts`), Vite добавляет base `/GameMR/`.

## Как устроено
- `src/ui/menu/MainMenu.tsx` — экран, пять живых `<button>`, окна «Настройки» (Звук / Изображение / Сохранения), «Авторы», «Новая игра» (подтверждение), экран «Сеанс завершён».
- `src/ui/menu/menuScene.ts` — контуры окна, импоста, стола, лампы и место логотипа/меню в долях кадра 1672×941 (сняты с чистого фона), расписание грозы, настройки эффектов.
- `src/ui/menu/atmosphere.ts` — один Canvas: три прохода струй дождя и капли только внутри стекла, вспышка 1–2 импульса раз в 12–30 с, отражения на столе, лампа, пылинки. Автоснижение качества при медленных кадрах (класс `fx-lite`), остановка на скрытой вкладке и при размонтировании.
- Слои художника (дождевое стекло ×2, луч с пылью, разряд) — DOM-слои с CSS-анимацией; разряд показывается только во время вспышки. Статичная молния фона не мигает.
- `App.tsx`: экран `menu | game`; в меню `useGameLoop(false)` — время не идёт; «Главное меню» в окне сохранений ставит смену на паузу; «Продолжить» возвращает её на паузе.
- «Продолжить» активно только при восстановленном автосохранении или идущей в вкладке кампании; иначе — причина («Сохранённой игры нет», «Автосохранение повреждено», «Хранилище браузера недоступно»).
- «Новая игра» сразу перезаписывает автосохранение (перезагрузка не вернёт старую кампанию); ручные слоты не трогает.

## Отличия от референса (на решение художника)
- Чистый фон пакета отличается от референса: нет багряного стяга на левой стене и ноутбука на столе. Использован чистый фон как есть, ничего не дорисовано.
- В референсе пункты без плашек, выделенный — плашка с ромбом. Так и сделано: в покое только надпись, при наведении/выборе — плашки художника; неактивное «Продолжить» — плашка disabled.
- Звуков дождя/грома/помещения в пакете нет — в настройках честно сказано, что они появятся позже. Музыка меню — `menu_theme.mp3`.

## Тесты
`tests/unit/menu.test.tsx`, `tests/e2e/menu.spec.ts` (кнопки, клавиатура, касание, сохранения, повреждённый слот, перезагрузка, вспышки, снижение движения, музыка, скорость). Игровые тесты стартуют сразу с игры (`__GAMEMR_SKIP_MENU__` в `tests/unit/setup.ts` и `tests/e2e/fixtures.ts`).
Скорость в тестовом браузере без видеокарты: 1366×768 ≈ 44–60 кадров/с, 1920×1080 ≈ 25–60 (после автоснижения). На реальном устройстве нужна проверка.
