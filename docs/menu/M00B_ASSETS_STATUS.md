**Нельзя ставить `integrated` или сообщать пользователю, что бинарные изображения загружены на GitHub, пока не выполнен реальный импорт.** Отдельная текстовая спецификация и SVG не заменяют главную картину.

## Как Claude импортирует именно эти файлы

1. Получить от владельца проекта файл `GameMR_M00B_Claude_Handoff_v1.zip` (прикрепление в среду разработки или локальный путь).
2. На своей рабочей ветке выполнить:
   ```bash
   python scripts/import_m00b_assets.py /путь/к/GameMR_M00B_Claude_Handoff_v1.zip
   ```
3. Проверить PNG/WebP, альфу, пути, открыть превью в браузере и зарегистрировать **реальные** файлы в `assets/manifest.json`.
4. Включить импорт в PR для просмотра художником. Не изменять W3-карту, утверждённые UI, игровое ядро без технической необходимости.
