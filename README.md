# Мир Раскола: Право на порядок — GameMR

Одиночная браузерная стратегия об управлении городской безопасностью Багряных домов. **Отдельный проект, не TKGame.**

## Запуск и проверка

Опубликованная версия (последний принятый этап): **https://bunkovde-lab.github.io/GameMR/**

Локально нужен Node.js 20+:

```bash
npm ci
npm run dev          # http://localhost:5173, с телефона в той же сети: npm run dev -- --host
npm run check        # линтер, типы, unit-тесты, сборка, браузерные тесты
```

Структура кода: `src/ui` — интерфейс (React), `src/core` — игровое ядро (чистые функции, `reduce(state, command)`), `src/persistence` — сохранения, `content/` — данные и баланс (provisional), `tests/unit` и `tests/e2e` — тесты.

## Зафиксированные ограничения
- Шесть районов города, **без механики захвата территорий**.
- Утверждены художественный арт карты и композиции экранов; картинки — референсы, а не готовые интерактивные кнопки.
- 12 сотрудников на старте расчётного среза; 24 на поздних макетах — демонстрация, а не новый базовый штат.
- Экономические цифры, написанные на артах, не являются утверждённым балансом.
- Сотрудники, происшествия, финансы, расследования, медицина и политика должны работать на единой модели данных.
- Сначала **W0: аудит** существующего прототипа, затем реализация с отдельной приёмкой каждого этапа.
