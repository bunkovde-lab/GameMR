# Claude Code — инструкция для GameMR

## Назначение
Разрабатывать **«Мир Раскола: Право на порядок»** как одиночную браузерную стратегию о руководителе городской безопасности Преемства (Багряные дома), первоначально ПК и горизонтальный планшет, затем мобильный интерфейс. Это **не** проект TKGame, не «Пепел помнит» и не стратегия захвата районов.

## Обязательные источники (читать в указанном порядке)
1. `docs/GameMR_Единое_ТЗ_v2_0.md` — главный производственный контракт, 22 экранных режима и поэтапная сборка W0–W10.
2. `docs/DECISIONS_AND_CONFLICTS.md` — открытые/неутверждённые числа и имена.
3. `docs/map/W3_MAP_INTEGRATION_SPEC.md` и `docs/map/W3_ACCEPTANCE_TESTS.md` — технический контракт карты.
4. `docs/ART_STYLE_GUIDE.md`, `docs/ASSET_CATALOG.md`, `docs/UI_ASSET_CONTRACT.md` — художественный контракт и ассеты.
5. `docs/work/WORK_START_PROMPT.md` — первая задача аудита W0.

Если документы противоречат друг другу — не выдумывать разрешение, отметить его в отчёте и issue. Точные цифры на иллюстрациях **не балансные данные**.

## Ответственность
- Пользователь утверждает итоговый вид и игру.
- ChatGPT — художественная концепция, арт-ассеты, механики и дизайн-проверка; загружает одобренные арт-исходники в GitHub.
- Claude Code — программирование, интеграция, тесты, сборки и PR.
- Не перерисовывать утверждённую карту/компоновки без нового запроса. Не подменять арт случайным генеративным UI.
- Не заявлять, что ассет доступен, пока его реальный файл не присутствует в репозитории.

## Процесс реализации
1. **W0: аудит репозитория** — какие файлы реально есть; что отсутствует; архитектура; поддерживаемые браузеры; план первой playable-сборки. Если игрового кода нет, так и сказать.
2. Далее — короткие самостоятельные задачи: карта/слои → вызов → готовый отряд → маршрут → исход → отчёт → сохранение.
3. В каждой задаче: краткий план, минимальные изменения, тесты (в том числе touch), скриншот или видео, список ограничений, ссылка на PR.
4. Новые игровые данные — отдельно от UI; все значения экранов выводить из единого состояния игры. Сохранения должны восстанавливаться детерминированно.
5. Работать в отдельной ветке и создавать PR, **не перезаписывать main и не выполнять force push**.
6. Не расширять объём задачи без согласования, не генерировать заново все 22 экрана и не переписывать канон.

## Неизменяемые решения
- Шесть районов города — события/патрули, **без захвата территорий**.
- Карта W3 основана на последнем утверждённом арте 1672×941; точность геометрии проверяется поверх настоящего файла.
- Художественные экраны служат **референсами композиции**, а не готовыми рабочими панелями с кнопками.
- 12 сотрудников на старте расчётной модели; 24 на артах — демонстрационные числа.
- Экономика РЕ / млн ₽, политические имена с изображений, вероятность/стоимость на артах — **не утверждены**.
- UI на русском, landscape-first, читаемые интерактивные элементы, ясные состояния кнопок и альтернативы drag-and-drop для сенсорного управления.
- Игровая стратегия: дефицит ресурсов, постоянные потери и ранения, неполная информация, юридические и политические последствия; не все исходы должны быть идеальными.
