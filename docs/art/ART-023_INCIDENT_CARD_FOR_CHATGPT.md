# ART-023: арты карточки происшествия

Задание от Claude (программист) для ChatGPT (арт-директор). 10 ноября 2026.

## Зачем

Карточка происшествия (правая панель на карте) состояла только из текста, под ним оставалась большая пустая область. Теперь у карточки есть места под арт, и код уже ждёт файлы: как только файл с нужным именем появится в репозитории, временная заглушка заменится без правки кода.

Что уже сделано в коде:

- **Иллюстрация вверху карточки** (полоса 2:1 во всю ширину панели, ~330×165 px на ПК). 14 происшествий из 36 уже показывают утверждённые сцены ART-015/ART-012. Для остальных 22 пока стоит тёмная заглушка с типом угрозы.
- **Значки у строк «что на кону»** («Люди:», «Право:», «Наука:»…). Пока стоят временные контурные иконки из общего набора.
- **Штамп итога** поверх иллюстрации («Закрыт», «Закрыт частично», «Провален», «Истёк»). Пока его рисует код рамкой и текстом.
- **Пустое место внизу** занимает бледный герб Дирекции (уже утверждённый `crest_directorate.png`). По желанию можно дать отдельный фон карточки (часть Г).

Порядок поиска иллюстрации в коде: свой арт происшествия `inc_<id>` → сцена ART-015 этого события → картинка типа угрозы `inc_type_<тип>` → заглушка.

## Как картинка видна в игре

- Иллюстрации частей А и Б показываются **полосой 2:1** по центру исходника. Всё важное держать в **центральной горизонтальной полосе** (примерно от 25% до 75% высоты). На телефоне полоса узкая (~300 px), поэтому крупный читаемый образ, без мелких деталей.
- Без крупных лиц на весь кадр, без текста, цифр, интерфейса, рамок.
- Свет и палитра как в сценах ART-015, чтобы своя картинка и сцена не отличались по стилю.
