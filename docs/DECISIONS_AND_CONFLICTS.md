# 17. Открытые решения и разрешение конфликтов

| ID | Вопрос | Рабочий режим, пока не согласовано |
|---|---|---|
| OPEN-01 | Валюта/масштаб денег: РЕ из baseline или визуальные «млн ₽» | симуляция использует РЕ из v1.0; числа артов — декоративные; без тайного курса конверсии |
| OPEN-02 | Финальная стоимость найма/лечения/курсов/модификаций | конфиг v1.0 и проверки; новые арты не фиксируют цену |
| OPEN-03 | 12 стартовых сотрудников vs 24 на макетах | старт 12, 24 — возможный поздний штат/показываемая коллекция |
| OPEN-04 | Названия и портреты шести Домов в политическом макете | Имена утверждены Дмитрием 2026-11-09: Ротан, Вельт, Севрин, Тессен, Варек, Астэр (h1–h6 по порядку списка). Открыто: подтвердить соответствие имён политическим функциям; гербов Домов в репозитории нет; портреты Домов не утверждены |
| OPEN-05 | «Неисполненный жребий» vs дело «Порог» №417 | первая линия из ТЗ v1.0; «Порог» — референс-демо, включать после сюжетного решения |
| OPEN-06 | Состав временных и постоянных отрядов, транспортные вместимости | конфиг; имена «Аксон», «Вектор» и другие проверять по реестру; не копировать случайное «группа A» |
| OPEN-07 | Проценты отношений, исследований, биологии, правовой защиты с изображений | не переносить в ядро; функциональные эффекты + отдельные балансные тесты |
| OPEN-08 | Список конкретных сюжетных персонажей, их канонические данные | переносить только после сверки с последним лором и утверждения; имена с экранов временные |
| OPEN-09 | Публичный сайт, GitHub-репозиторий и домен публикации | выбрать отдельно; не использовать TKGame без разрешения |
| OPEN-10 | Поддержка портретного телефона для первой playable-сборки | функционально предусмотрена; full UX/gate на W10 |

**Изменения открытых пунктов вносить в `DECISIONS.md`, затем обновлять версию ТЗ, конфиг и тесты одновременно.** Порог баланса и текст на художественном изображении нельзя «исправлять» принудительной настройкой ядра.
