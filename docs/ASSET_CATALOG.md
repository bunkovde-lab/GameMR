## Карточка нового ассета
При создании заполнить ID, смысл, каноническую привязку, путь к исходнику, целевой формат, размеры, наличие альфы, статус (draft / review / approved / integrated), зависимости, правила кадрирования, проверку в UI и ссылку на GitHub PR.

## Порядок арт-поставки
1. Перенести **оригинальный** утверждённый арт карты; не создавать альтернативу.
2. Подготовить независимые маркеры вызовов и отрядов.
3. Подготовить декор и элементы панелей без текста.
4. Разделить портреты первых сотрудников и состояния.
5. Подготовить сцены происшествий только после фиксации первой playable-механики.

## Важное
Если оригинальный файл карты недоступен из репозитория, Claude должен явно сообщить об этом на W0, не подменять художественную карту произвольным изображением.
